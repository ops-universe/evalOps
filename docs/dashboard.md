# Local dashboard
Start the website with `cd website-react && npm ci && npm run dev`. Navigate to Dashboard and import version 1 deterministic, RAG, agent or multi-suite gate JSON evidence. Optionally import a compatible baseline. Inspect aggregate metrics, choose a per-case metric chart, filter failed cases and export the selected normalized view. The browser does not transmit report contents. Imported reports are untrusted and not independently authenticated. Files are limited to 5 MiB; the visible table/chart is limited to the first 100 matching cases, export includes all selected cases. Browser interaction verification remains pending; model tests and production build are covered by CI.
