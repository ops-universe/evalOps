# Threat model

Untrusted case text is data, not instructions. The deterministic core performs no eval, shell execution, network or model calls. The separate judge API requires explicit opt-in and additional external-data permission. Reject unsupported metrics, empty expectations, duplicates and invalid thresholds. Trusted application code chooses the threshold, not an evaluated response. No claims of semantic correctness. Future risks include prompt injection, data leakage and judge manipulation; require explicit adapter permissions and evidence before enabling them. CLI dataset size limits, constrained IDs and strict field validation are implemented; the direct engine API remains a lower-level interface. Report hashes and identifiers are not anonymized. Evidence signing remains pending. Judge prompts separate rubric and untrusted data but cannot guarantee injection resistance. Custom adapters are trusted code; external provider authorization and live compatibility are caller responsibilities.

## Acceptance boundaries
Treat local datasets and imported reports as untrusted data, never executable instructions. JSON CLI input is bounded to 5 MiB, strict UTF-8 and regular files; nonblocking opens mitigate FIFO hangs. Gate path containment assumes a trusted, stable local configuration directory; concurrent hostile filesystem mutation is outside this guarantee. Reports and hashes are not signatures, and supplied labels are not independently verified. CI fixture baselines test mechanics, not independent historical performance. Review trusted baselines separately. Agent evaluation detects deviations but is not runtime authorization. Groundedness scorers are trusted injected code; deadlines abort cooperative scorers but cannot terminate arbitrary synchronous code or prevent side effects. Explicit HTTPS provider endpoint and external opt-in are required; caller must trust endpoint and injected adapter, manage credentials and data policy. Live provider compatibility is unverified. Browser reports remain local and do not authenticate provenance. No production security certification or release is implied.
