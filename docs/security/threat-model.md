# Threat model

Untrusted case text is data, not instructions. No eval, shell execution, network or model calls. Reject unsupported metrics, empty expectations, duplicates and invalid thresholds. Trusted application code chooses the threshold, not an evaluated response. No claims of semantic correctness. Future risks include prompt injection, data leakage and judge manipulation; require explicit adapter permissions and evidence before enabling them. CLI dataset size limits, constrained IDs and strict field validation are implemented; the direct engine API remains a lower-level interface. Report hashes and identifiers are not anonymized. Evidence signing and semantic scoring remain pending.
