# Threat model

Untrusted case text is data, not instructions. The deterministic core performs no eval, shell execution, network or model calls. The separate judge API requires explicit opt-in and additional external-data permission. Reject unsupported metrics, empty expectations, duplicates and invalid thresholds. Trusted application code chooses the threshold, not an evaluated response. No claims of semantic correctness. Future risks include prompt injection, data leakage and judge manipulation; require explicit adapter permissions and evidence before enabling them. CLI dataset size limits, constrained IDs and strict field validation are implemented; the direct engine API remains a lower-level interface. Report hashes and identifiers are not anonymized. Evidence signing remains pending. Judge prompts separate rubric and untrusted data but cannot guarantee injection resistance. Custom adapters are trusted code; external provider authorization and live compatibility are caller responsibilities.
