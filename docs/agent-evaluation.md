# Agent trace evaluation
Import evaluateAgent from src/agent.mjs. Version 1 synthetic or local datasets contain cases with allowedTools, expected and actual ordered calls (tool and JSON object args), expectedCompleted and actualCompleted booleans. No tool is invoked. Positional tool accuracy and exact canonical argument accuracy divide matches by the larger trace length; both empty traces score one. Any unexpected tool name outside the supplied allowlist fails regardless of completion. Sequence, arguments and completion expectations must match exactly. Completion labels are supplied by the caller, not inferred or independently verified. Argument validation is exact expected-value comparison, not a general tool JSON Schema validator or authorization engine. Reports omit argument values but include tool identifiers and dataset hashes; use synthetic or appropriately authorized data. Run `node src/cli.mjs agent-validate datasets/agent-synthetic.json` or `node src/cli.mjs agent-run datasets/agent-synthetic.json --out agent-report.json`. Exit codes 0 pass, 1 failed gate, 2 invalid input. Validation checks structure plus semantic constraints; the published schema is a structural contract, not a complete runtime validator. Unknown case/call fields are rejected. Reports use exclusive creation.
